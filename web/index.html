        01 · Flames in orbit

        Same plastic rod, four oxygen levels. Real flight video from the ISS.

        NASA's BASS-II experiment burned the same quarter-inch acrylic (PMMA) rod at different oxygen levels inside the station's glovebox. Move through the oxygen levels: as oxygen drops, the flame shrinks, loses its soot and turns blue, and it still burns below what Earth tests allow.

        Solids, liquids and gases.

        Every BASS-II flight burn on camera, by oxygen.

        Clips are from NASA PSI raw data (CC0), cropped to the flame and sped up as marked. Each card shows the oxygen measured in the glovebox before ignition, the airflow steps the crew set and the carbon monoxide the burn added. Camera exposure changes between and within tests, so compare shape and color, not brightness. Eight sequences that show the camera monitor or no flame are left out.

        06 · Ask SI

        Ask the archive. Get an answer you can check, sentence by sentence.

        An SI (super intelligence, as the challenge calls it) model writes each briefing from numbered evidence computed by the pipeline. Code publishes it only if every sentence cites evidence, every number appears in that evidence and nothing reads as a safety verdict.

        07 · Data & validation

        Reproducible pipeline. Honest validation.

        One command rebuilds everything from NASA's public API. Every correction is logged, and the model is scored only on test days it never saw.

          Model vs baselines

          Held-out validation.

          AUC: ranking quality (0.5 = chance). Brier and log loss: calibration (lower is better). The simpler logistic model beats gradient boosting on held-out days, so it is the one deployed.

          Calibration

          Predicted vs observed.

          Out-of-fold predicted probability vs observed self-extinction rate.

          Data-quality log

          Every correction to NASA's tables.

          Reproduce: python scripts/fetch_psi.py data/psi PSI-… then python -m pipeline.run

          SI verification firewall

          Every briefing, checked.

          Checks per sentence: at least one citation to an existing evidence item; every number present in the cited items; no safety verdict (“is safe”, “certified”, “guaranteed”…); the evidence pack unchanged since the draft was written. A briefing that fails shows the evidence itself, labelled “Evidence brief”. Regenerate with python scripts/si_generate.py.
